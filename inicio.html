📘 Presentación del material

Este espacio web presenta un material educativo sobre el uso de aplicaciones móviles como apoyo al aprendizaje del desarrollo web Front-End.

El contenido está organizado de forma horizontal para facilitar la navegación entre los apartados principales del curso, manteniendo una estructura clara, ordenada y accesible.

🎯 Propósito del recurso

El propósito de este material es brindar una guía de aprendizaje sobre los fundamentos del Front-End y el uso de herramientas digitales que permiten estudiar HTML, CSS y JavaScript de manera flexible y progresiva.
